# Design language

**Nocturne**: dark, compact, token-driven; single blurple accent `#9184d9`, Inter for UI
text, JetBrains Mono for code, Phosphor icons, outlined actions, 8px radii, ~0.7× density.
Tokens live in this directory (`app-tokens.css`, `nocturne.css`, `theme.css`,
`monaco-theme.ts`); plan in
[`docs/design/shipped/ui-redesign-plan.md`](../../../docs/design/shipped/ui-redesign-plan.md).
